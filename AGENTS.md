# Power BI project instructions

## Skill routing

Load the required skill before starting the task:

- Semantic model changes: load `semantic-model-authoring`.
- Report changes: load `powerbi-report-cli`.
- Project documentation: load `powerbi-documentation`.

If a task covers more than one area, load every applicable skill.

## Semantic model authoring

- Use the Power BI Authoring MCP for all semantic model changes.
- Do not edit TMDL files directly.
- Connect the Power BI Authoring MCP to the PBIP folder by default.
- Connect to the local Power BI Desktop instance only when the task explicitly requires it or the PBIP folder is unavailable.
